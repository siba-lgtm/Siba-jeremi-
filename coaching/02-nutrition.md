# 🍽️ Nutrition du footballeur

## Les 5 règles d'or
1. **3 repas + 1-2 collations**, jamais sauter le petit-déjeuner.
2. **Chaque assiette** = ½ légumes · ¼ protéines · ¼ féculents (plus de féculents les jours d'entraînement/match).
3. **Eau : 2 à 3 L / jour** (+ 500 ml par heure de sport). Urine claire = bien hydraté.
4. **Limiter** : sodas, jus industriels, fast-food, friture → 1 « repas plaisir » par semaine, sans culpabilité.
5. **Protéines à chaque repas** pour récupérer et construire du muscle.

## Les bons aliments
- **Protéines** : œufs, poulet, poisson (sardines, thon, maquereau), viande maigre, haricots, lentilles, pois chiches, yaourt.
- **Féculents (énergie)** : riz, pâtes, igname, banane plantain, patate douce, flocons d'avoine, pain complet, attiéké, foutou.
- **Légumes / fruits** : épinards, gombo, carottes, tomates, banane, mangue, orange, papaye.
- **Bons gras** : avocat, arachides/cacahuètes, huile d'olive, poisson gras.

## Journée type
| Moment | Exemple |
|---|---|
| Petit-déj | Flocons d'avoine + lait + banane **ou** 2-3 œufs + pain complet + fruit |
| Collation 10h | Yaourt + poignée de cacahuètes |
| Déjeuner | Riz + poulet/poisson + légumes/sauce légère |
| Collation 16h-17h (avant entraînement) | Banane + pain ou fruit + eau |
| Dîner | Igname/patate douce + poisson ou œufs + légumes |

## Autour du match
- **Veille** : repas riche en féculents (pâtes, riz), dodo tôt.
- **3 h avant** : repas digeste (riz/pâtes + viande blanche), pas de gras ni friture.
- **1 h avant** : banane + eau.
- **Après (dans l'heure)** : protéines + féculents (ex. riz + poulet, ou lait + pain + banane) + beaucoup d'eau.

## Liste de courses de base
Œufs, poulet, sardines/thon en boîte, riz, avoine, pâtes, bananes, fruits de saison, légumes, yaourts, cacahuètes, avocat, eau.
