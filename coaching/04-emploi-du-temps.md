# ⏰ Gérer son emploi du temps

## La méthode
1. **Dimanche soir (15 min)** : planifier la semaine — cours/travail, entraînements, match, séances perso, révisions.
2. **Chaque soir (5 min)** : écrire les **3 priorités** du lendemain.
3. **Blocs de temps** : 1 bloc = 1 tâche. Téléphone en mode avion pendant les blocs.
4. **Règle des 2 minutes** : si ça prend moins de 2 min, fais-le tout de suite.
5. **Heure de coucher fixe** : c'est elle qui décide de ta journée de demain.

## Journée type (à adapter à tes horaires)
| Heure | Activité |
|---|---|
| 6h30 | Réveil, verre d'eau, routine peau, 5 min mobilité |
| 7h00 | Petit-déjeuner |
| 7h30 – 16h | Cours / travail (collation à 10h) |
| 16h30 | Collation pré-entraînement |
| 17h – 19h | Entraînement / séance perso |
| 19h30 | Douche + dîner |
| 20h30 – 21h30 | Révisions / projets / lecture |
| 21h30 | Écrans off, préparer affaires du lendemain, 3 priorités |
| 22h30 | Dodo (8 h de sommeil) |

## Voleurs de temps
- Réseaux sociaux : limite d'usage dans les paramètres du téléphone (ex. 1 h/jour).
- Téléphone hors de la chambre ou loin du lit la nuit.
- Jeux vidéo : seulement après les priorités du jour.

## Checklist quotidienne
- [ ] Sommeil ≥ 7h30
- [ ] 2-3 L d'eau
- [ ] 3 repas + collation
- [ ] Séance / entraînement (ou repos prévu)
- [ ] Routine peau matin + soir
- [ ] 3 priorités du jour faites
