# Vidéos TikTok – version allemande (concept « Du warst das Kind, das… »)

Trois vidéos **originales** qui reprennent le concept de la vidéo de référence :

- narration à la 2ᵉ personne (« Du… ») ;
- un enfant qui déteste un aliment ;
- la famille qui ne le croit pas ;
- un cours à l'école qui lui donne raison (vraie info scientifique) ;
- une chute drôle à la fin.

Le style est le même : dessin animé, format vertical 9:16, sous-titres mot par mot en majuscules avec les mots-clés en jaune et un zoom à chaque plan.

| Fichier | Sujet | Durée |
|---|---|---|
| `output/koriander.mp4` | Le coriandre a goût de savon (c'est génétique) | 42 s |
| `output/milch.mp4` | Le lait donne mal au ventre (intolérance au lactose) | 44 s |
| `output/orangensaft.mp4` | Dentifrice puis jus d'orange = amer (chimie) | 48 s |

Chaque vidéo a aussi son fichier `.srt` (sous-titres avec timing).

> ⚠️ **Pas encore de voix off.** L'environnement n'avait pas accès aux services
> de synthèse vocale (réseau bloqué). Les vidéos ont une musique de fond et des
> sous-titres. Pour ajouter la voix, deux options :
> 1. **CapCut** : importer la vidéo, *Texte → Ajouter du texte*, coller le script
>    ci-dessous, puis *Texte en voix* et choisir une voix allemande. Garder nos
>    sous-titres et baisser la musique à ~30 %.
> 2. Autoriser `pypi.org`, `files.pythonhosted.org` et `speech.platform.bing.com`
>    dans les paramètres réseau de l'environnement. Je peux alors générer la voix
>    allemande automatiquement et recaler les sous-titres dessus.

## Créer de nouvelles vidéos

Les vidéos sont générées par code (`generator/`) :

1. Ajouter une histoire dans `generator/stories.js`, sur le même modèle : des scènes avec un décor, des personnages, des objets, le texte et les mots-clés.
2. Lancer :

```bash
cd videos/generator
node render.js <histoire> ../build            # images + vidéo muette + .srt
python3 music.py ../build/<histoire>.timeline.json ../build/<histoire>.music.wav
ffmpeg -i ../build/<histoire>.silent.mp4 -i ../build/<histoire>.music.wav -c:v copy -c:a aac -shortest ../output/<histoire>.mp4
```

`node render.js <histoire> <dossier> --preview` sort une image par scène, pour vérifier rapidement.
La musique est synthétisée par le script : elle est libre de droits.
